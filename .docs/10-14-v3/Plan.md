## 1. 背景与目标

用户截图显示记账金额输入框出现内外两套蓝色焦点边框；细分标签抽屉的遮罩仅覆盖居中的设置内容区，面板未贴合视口右边缘。代码探索还确认了抽屉关闭层级冲突和新增失败时丢失输入的问题。

目标：金额输入只有一套完整且可辨识的焦点表现；桌面抽屉贴合视口右侧、遮罩覆盖整个视口，移动端保持底部面板；标签操作失败保留输入；关闭与键盘交互遵循最上层优先。沿用项目既有 Fluent 2 / Fluent-Slate Hybrid 设计，不增加依赖、不改变后端接口或全站布局。

## 2. 阶段划分

| Phase | 输入 | 输出 | 验收标准 |
|---|---|---|---|
| 1：归位焦点与模态层 | 两张截图、现有焦点规则与页面动画层 | 可被控件覆盖的全局焦点默认值；视口级抽屉与共享删除确认 | 金额无内层矩形框；键盘按钮焦点可见；动画期间与结束后遮罩全屏 |
| 2：修复抽屉生命周期 | 现有分类 ID 派生数据、标签 CRUD 回调 | 一致关闭路径、最上层键盘处理、失败保留输入 | Esc 不穿透删除确认；关闭后状态与滚动恢复；新增失败可重试 |
| 3：验证与交付维护 | 前两阶段差分 | 编译、自检与浏览器回归记录；同步项目文档、归档与提交 | 检查通过，已有用户改动不被纳入提交，完成文档按工作流归档 |

## 3. 架构决策

| 决策项 | 选择 | 理由 |
|---|---|---|
| 焦点规则 | 全局默认进入低优先级样式层，保留输入控件已有的自定义焦点样式 | 根因是 CSS 层优先级；避免局部 important 或取消全站键盘焦点 |
| 模态挂载 | 复用 React DOM Portal，将抽屉及共享确认挂到 body | 隔离动画祖先的定位与堆叠上下文，保留 React 状态与事件关系 |
| 动画 | 保留页面入场及现有抽屉响应式入场 | 不用取消全站动画规避局部挂载缺陷 |
| 数据 | 继续使用分类 ID 和父级数据派生标签列表 | 不复制标签数组，不引入镜像状态 |
| 关闭 | 收敛抽屉关闭函数，确认优先于编辑，编辑优先于抽屉 | 防止 Esc 同时取消删除和关闭底层面板 |
| 键盘 | 打开时首焦点、关闭时恢复仍存在的触发点、Esc 最上层优先 | 保持基础交互；本轮不实现手写 Tab 环或删除后焦点仲裁，焦点隔离留待专项 |
| 请求失败 | 新增回调在提示后抛出，表单捕获并保留草稿 | Promise 成功和失败语义应与既有重命名回调一致 |

界面层级继续沿用既有令牌：背景为 Layer 0，设置面板为 Layer 1，导航与悬浮按钮为 Layer 2，抽屉与删除确认为 Layer 3。桌面抽屉宽度保持 420px、全视口高度；窄屏保留底部面板和 85dvh 高度上限，头尾常驻、正文独立滚动。焦点边框、遮罩、材质、圆角及阴影消费既有令牌。

## 4. 风险清单

| 风险 | 依据 | 缓解措施 |
|---|---|---|
| 焦点默认分层影响其他输入 | 登录、金额、手续费、设置输入均声明 outline-none | 检查各输入仍有边框或外层焦点表现，同时验证按钮默认焦点 |
| Portal 改变 DOM 位置而保留 React 事件冒泡 | 设置确认与抽屉处于同一页面状态域 | 保留面板点击阻止冒泡，逐项检查遮罩/内部点击 |
| 删除确认和抽屉各自监听 Esc | 当前均监听 window | 设置监听器在确认打开时让位；确认焦点恢复不能触发抽屉首焦点重置 |
| 全局 N 可从抽屉按钮触发 | 快捷键仅排除输入框与已有记账/登录窗口 | 在快捷键入口按现存 modal DOM 阻断，不同步另一份抽屉状态 |
| 新增失败被清空 | 父回调捕获但不抛出，子表单 await 后直接清空 | 恢复异常契约并在表单捕获，单次 Toast，草稿保留 |
| 浏览器验收环境受限 | 项目注明准备的 9222 实例暂不可用 | 执行时先确认可用性；编译不代替视觉验收，未能运行的项如实记录 |

## 6. 评审修订记录（v1.1）

- 采纳：移除手写焦点环、删除后焦点仲裁和小屏圆角微调。项目已将焦点陷阱留待专项，本轮保持基础首焦点、关闭恢复与 Esc 分层。键盘焦点仍可 Tab 到背景是本轮未解决的限制，不将此描述为完整模态可访问性。
- 采纳：自检按金额、抽屉、抽屉内删除确认三个独立状态运行，缺少前置节点立即失败，避免条件分支造成假通过。
- 采纳并细化：函数入口以同步提交锁阻止重复请求，待提交 state 仅控制禁用；仅检查 state 不能覆盖同一渲染间隔内的两次 submit。
- 校正：记账窗口与抽屉并非绝不可能同时存在。记账入口全局常驻，当前 N 快捷键也未排除抽屉；因此保留快捷键阻断修复，测试不依赖异常叠加状态。
- 保留：默认焦点分层与 Portal 结构修复；动画关键帧结束值为 transform: none，执行时应分别检查动画中与动画后表现，不把固定包含块持续存在简化为非空 transform 永久保留。

## 7. Subagent 协同规划

本轮两个缺陷涉及同一全局样式和模态层，相关修改量小，键盘与异步状态强关联。独立代理需要重复加载上下文，无法带来有效并行收益；规划与交付任务均由主线处理，不委托。Main-hybrid 本轮仅完成 Explore → Plan → Formulate Tasks，产出文档后交接，等待明确执行指令。
